# Math Mentor Pro - 智能数学特级教师助手

Math Mentor Pro 是一款专为中学数学教育设计的 AI 辅助工具。它基于 Google Gemini 3 Pro 模型，结合深度视觉识别与数学逻辑推理，为老师和学生提供“特级教师”级别的解题诊断、几何分析及试题变式功能。

## 1. 需求方案总结

### 1.1 核心痛点
- **批改压力大**：传统批改仅关注结果，难以快速定位学生的逻辑断层。
- **手写识别难**：学生手写公式、计算过程繁杂，传统 OCR 难以精准还原逻辑。
- **几何解析难**：几何图形中的隐含条件（垂直、平分等）难以通过文字描述，需要视觉直觉。
- **备课耗时**：老师寻找同类变式题需要翻阅大量资料。

### 1.2 解决方案
- **逻辑分步诊断**：不直接给答案，而是按步骤还原 LaTeX 公式，并指出具体错误原因（计算、公式、逻辑）。
- **几何视觉大脑**：通过 Gemini 2.0/3 系列模型的视觉能力，自动识别几何标注并给出辅助线建议。
- **智能变式生成**：一键生成知识点相同的变式题，辅助个性化教学。

## 2. 使用说明

### 2.1 快速上手
1. **选择模式**：根据需求选择“解题批改”、“几何分析”或“试题变式”。
2. **拍摄/上传**：点击“上传图片”，移动端会自动唤起摄像头。
3. **补充说明**：在输入框内填入特殊要求（如“重点看第三步”）。
4. **开始分析**：点击“AI 深度分析”，稍等片刻即可获得详尽的诊断报告。

### 2.2 提示词建议
- **批改时**：尽量拍摄清晰的卷面，光线均匀。
- **几何时**：确保图形标注（A, B, C 等字母）在图片范围内。

## 3. 部署与技术栈

### 3.1 移动端与 PWA
本项目已适配移动端浏览器（H5），并支持 PWA 迭代：
- **响应式布局**：基于 Tailwind CSS 适配各种屏幕尺寸。
- **PWA 支持**：支持“添加到主屏幕”，离线缓存基础资源，体验接近原生 App。
- **触摸优化**：优化了按钮点击态和滚动体验。

### 3.2 Cloudflare Pages 部署
本项目非常适合部署在 Cloudflare Pages 上：
1. **连接仓库**：在 Cloudflare Dashboard 中选择 "Pages" -> "Connect to Git"。
2. **构建设置**：
   - 框架预设：`Vite`
   - 构建命令：`npm run build`
   - 输出目录：`dist`
3. **环境变量**：
   - 在 "Settings" -> "Environment variables" 中添加 `GEMINI_API_KEY`，值为您的 Google AI API Key。
4. **自定义域名**：支持绑定您的个人域名，并自动开启 HTTPS。

### 3.3 技术架构
- **前端**：React 19 + TypeScript + Vite
- **UI**：Tailwind CSS + Lucide React
- **渲染**：React Markdown + KaTeX (支持数学公式完美展示)
- **AI**：Google Gemini 3 Pro (通过 `@google/genai` SDK)
- **部署**：Cloudflare Pages / PWA
