# Math Mentor Pro - 智能数学特级教师助手

Math Mentor Pro 是一款专为中学数学教育设计的 AI 辅助工具。它基于 Google Gemini 3 Pro 模型，结合深度视觉识别与数学逻辑推理，为老师和学生提供“特级教师”级别的解题诊断、几何分析及试题变式功能。

## 1. 需求方案总结

### 1.1 核心痛点
- **批改压力大**：传统批改仅关注结果，难以快速定位学生的逻辑断层。
- **手写识别难**：学生手写公式、计算过程繁杂，传统 OCR 难以精准还原逻辑。
- **几何解析难**：几何图形中的隐含条件（垂直、平分等）难以通过文字描述，需要视觉直觉。
- **备课耗时**：老师寻找同类变式题需要翻阅大量资料。

### 1.2 解决方案
- **逻辑分步诊断**：不直接给答案，而是按步骤还原 LaTeX 公式，并指出具体错误原因（计算、公式、逻辑）。
- **几何视觉大脑**：通过 Gemini 2.0/3 系列模型的视觉能力，自动识别几何标注并给出辅助线建议。
- **智能变式生成**：一键生成知识点相同的变式题，辅助个性化教学。

## 2. 技术开发文档

### 2.1 技术栈
- **前端框架**：React 19 + TypeScript
- **样式处理**：Tailwind CSS (响应式 H5 优化)
- **数学渲染**：KaTeX + React-Markdown (支持复杂的 LaTeX 语法)
- **AI 引擎**：@google/genai (Gemini 3 Pro Preview)
- **图标系统**：Lucide React

### 2.2 核心模块说明
- `geminiService.ts`: 封装了系统指令（System Instruction），强制 AI 以“特级教师”的人设进行多模态交互。
- `MathRenderer.tsx`: 处理 AI 返回的 Markdown 内容，精准捕获并渲染 `$ $` 与 `$$ $$` 之间的数学公式，解决移动端公式溢出问题。
- `App.tsx`: 响应式布局核心，针对手机、平板、桌面端进行差异化适配。

### 2.3 关键逻辑
- **多模态输入**：支持图片上传与摄像头直接拍摄。
- **温度控制**：设置 `temperature: 0.1` 以确保数学推导的高严谨性。
- **Token 策略**：使用 Gemini 3 Pro 满足高难度的几何证明与微积分推演。

## 3. 使用说明

### 3.1 快速上手
1. **选择模式**：根据需求选择“解题批改”、“几何分析”或“试题变式”。
2. **拍摄/上传**：点击“上传图片”，移动端会自动唤起摄像头。
3. **补充说明**：在输入框内填入特殊要求（如“重点看第三步”）。
4. **开始分析**：点击“AI 深度分析”，稍等片刻即可获得详尽的诊断报告。

### 3.2 提示词建议
- **批改时**：尽量拍摄清晰的卷面，光线均匀。
- **几何时**：确保图形标注（A, B, C 等字母）在图片范围内。

## 4. 移动端 H5 优化特性
- **Touch-Friendly**：按钮尺寸优化，符合拇指点击区域。
- **原生相机适配**：通过 `capture="environment"` 属性实现快速拍摄。
- **自适应滚动**：针对数学公式的长行内容，支持横向丝滑滚动，不破坏页面布局。
- **视觉美化**：采用 Indigo & Slate 高级配色，营造严谨的学术氛围。
